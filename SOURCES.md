# Nguồn tham khảo và đối chiếu slide

- Chapter 04 slides.pptx của người dùng: chương HTML5/CSS3, không có trọn bộ Servlet xử lý khảo sát.
- https://github.com/hoangbaovk05-wq/ch04-web-ute : mã tham khảo do người dùng cung cấp. Giữ cấu trúc HTML / Servlet / JavaBean / JSP, tên tham số và phần lớn mã mẫu, rồi điều chỉnh giao diện, kiểm tra đầu vào và đóng gói triển khai. Kho tham khảo không kèm LICENSE tại thời điểm đọc; không gán giấy phép mới cho mã này.
- Logo dùng hình PNG nhúng trong slide 28 (thay logo có bóng của repo mẫu).
- Ảnh người dùng: bố cục Survey, logo, các trường và lựa chọn.

| Slide | Áp dụng trong bài |
| --- | --- |
| 5–12 | HTML5, head/title/body, h1/h2/p, label/input/br |
| 13–15 | header chứa logo |
| 28–31 | img, src, alt và logo Murach |
| 36–46 | CSS ngoài styles/main.css; selector thẻ, lớp, id; font, màu teal, margin, float và clear |
| 50–55 | form action/method=post, name/value, hidden action, text/email, required |
| 56–58 | input type=submit |
| 59–62 | checkbox độc lập, radio chung name, checked mặc định |
| 63–66 | select/option cho cách liên hệ |

CSS điều chỉnh kích thước cho ảnh yêu cầu, không chép nguyên chiều rộng 400px của ví dụ Email List trong slide. Ngày sinh dùng input type="date" như GitHub tham khảo và ảnh yêu cầu cập nhật, mở lịch có sẵn của trình duyệt. Servlet/JSP và Maven/Tomcat là phần bổ sung theo repo tham khảo để Submit hoạt động. Không thêm React, Spring Boot, JavaScript hay cơ sở dữ liệu.
